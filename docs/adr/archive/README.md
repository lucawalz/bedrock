# Archived architecture decision records

These records are the decision log from before the cluster was rebuilt from git in November 2026. They are kept for their reasoning and are no longer maintained. The architecture in force is recorded in the [current set](../README.md), which supersedes every record here. Statuses below are as they stood when the log was archived.

The records follow Michael Nygard's format: the context with the options weighed, the decision, and the consequences. A superseded record keeps its reasoning, including every option it rejected, rather than being trimmed to a pointer.

Number 0056 was never used. No record was written, withdrawn, or lost.
